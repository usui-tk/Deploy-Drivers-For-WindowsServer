## Cumulative aggregate defect found during hardening

Observed after successful Build:

- `all-releases-summary.json`: 27 artifacts / 551 drivers — correct cumulative count.
- `inf-topology.json`: 23 artifact references but `DriverCount=551` — internally inconsistent.
- Windows Server aggregate: 23 artifact keys / 1,928 rows — current-run only.
- Expected cumulative Windows Server rows: `551 drivers × 4 profiles = 2,204`.

The four retained artifacts missing from the lightweight topology/Server views were:

- `Adrenalin|Main|23.11.1|whql-amd-software-adrenalin-edition-23.11.1-win10-win11-nov3-rdna-combined.exe`
- `Adrenalin|Main|23.11.1|whql-amd-software-adrenalin-edition-23.11.1-win10-win11-nov3-rdna.exe`
- `ProEdition|MultiArtifact|26.Q1|amd-software-pro-edition-26.q1-win11-vega-polaris.exe`
- `ProEdition|MultiArtifact|26.Q1|amd-software-pro-edition-26.q1-winsvr2022-vega-polaris.exe`

Root cause: the package baseline still contained historical `inf-topology-collection/1.2` and `windows-server-applicability/2.1` aggregate shapes. 0.7.1 deliberately refused to silently coerce incompatible legacy Server rows, but it still included their driver totals from `all-releases-summary.json`, producing inconsistent derived views.

## 0.7.2 changes

1. Inspect index advances to `amd-graphics-driver-packages-index/3.1`. Each detail reference records `DetailJsonSha256` and `DetailJsonSizeBytes`. Historical 3.0 indexes remain readable for replay.
2. `driver-packages-integrity.json` validates every shard before Build: file existence, unique ArtifactKey/detail path, identity, driver/parse/WDF counts, size and SHA-256.
3. Build migrates historical 2.1 Server rows **in memory only** into the lightweight current aggregate shape. Historical canonical evidence is not rewritten.
4. Historical topology retention is derived from the retained `all-releases-summary.json`, so an old detailed topology schema cannot cause artifact references to disappear.
5. `build-integrity.json` requires cumulative summary/topology/Server views to agree on artifact coverage and driver totals. With four Server profiles, Server rows must equal cumulative driver count × 4.
6. Assessment now reports `DriverPackageShardIntegrity` and `BuildAggregateIntegrity`.
7. ProductSelection assessment now exposes evidence-conflict and ArtifactRole-transition counts.
8. Build-only reruns delete a stale `build-integrity.json` before preflight, preventing a previous PASS from masking a new preflight failure.
