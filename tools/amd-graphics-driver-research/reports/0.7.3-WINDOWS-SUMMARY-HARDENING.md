## Defect 1 — ProductSelection report formatting

0.7.2 embedded `if (...) {...} else {...}` directly as a parenthesized `-f` argument. Windows PowerShell interprets that form as a command invocation and produced the Japanese `if is not recognized` message shown by the user. The selection plan itself was valid.

0.7.3 reads optional fields through `Get-AmdOptionalIntProperty`, validates selection counts, and formats only resolved scalar values. Evidence conflicts (3) and ArtifactRole-transition tracks (21) remain visible provenance notes.

## Defect 2 — InfInspection assessment schema drift

Inspect emitted `amd-graphics-driver-packages-index/3.1`; shard-integrity and Build already supported both 3.0 and 3.1. The final assessment, however, only explicitly recognized 3.0 and therefore produced a false REVIEW.

0.7.3 centralizes the supported schema set and reuses it in assessment, shard-integrity validation, and Build.

## Additional hardening

- `RunAssessmentSelfTest` added to Test-stage readiness.
- Selection assessment validates stable-track, generation, artifact-selection, unique-artifact and SelectedArtifacts row consistency.
- Inspection assessment validates ArtifactCount against index rows and parse-failure bounds.
- `InspectionAssessmentConsistency` compares assessment/index counts with `driver-packages-integrity.json`.
- Unsupported future schemas remain fail-closed rather than silently accepted.
