# AMD Graphics Driver Research Toolkit 0.8.2 — Windows Publication Portability Hardening

The 0.8.1 Windows PowerShell 5.1 evidence completed all eight stages with `Pass` / exit 0. It selected, acquired, extracted and inspected 23 artifacts (482 INF records, zero parse failures) and built a cumulative public baseline of 27 artifacts / 551 drivers / 2,204 Windows Server rows. The separately supplied public surface has zero privacy findings and its publication manifest SHA-256 matches the private evidence publication reference.

The hardening target is cross-platform publication integrity. The 0.8.1 Windows manifest used host-native backslashes in 68 of 72 `RelativePath` values. Although Windows validation succeeded, this is not a stable repository-path representation for Linux GitHub Actions. Version 0.8.2 emits POSIX-relative paths, validates the exact file set plus size/SHA-256, and cross-checks public dataset counts before atomic promotion.
